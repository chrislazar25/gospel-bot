# Gospel lab feature map

Drive these journeys through `node local-lab/verify.mjs drive` after a fresh launch.

- [Send today's message](send.md) covers the public send route, replica competition, and the IST daily boundary.
- [Inspect delivery status](status.md) covers receipts and read-only status requests.
- [Hold or retry after failure](failures.md) covers proven rejection, uncertain acceptance, and restart durability.

The runtime schema, Compose file, and helper in `local-lab/` own the concrete contract. These files describe the user's observable behavior.
